# CASE-001 — Threat Hunting Record

## 1. Purpose

This document records proactive threat-hunting activities performed in support of CASE-001.

The objective is to determine whether the authentication activity associated with `198.51.100.25`, the `root` account, and `EVT-001012` is isolated or part of a broader activity pattern.

Threat hunting is performed against authorized laboratory telemetry.

No hunt result should be interpreted as proof of malicious activity unless the supporting evidence is sufficient.

---

## 2. Hunt Overview

**Case ID:** CASE-001

**Primary Alert:** `ALERT-CASE-001-DET-AUTH-001`

**Primary Detection:** `DET-AUTH-001`

**Primary Source IP:** `198.51.100.25`

**Primary Account:** `root`

**Primary Host:** `lab-auth-01`

**Primary Protocol:** SSH

**Primary Pivot Event:** `EVT-001012`

**Hunt Status:** Completed against currently available telemetry

**Environment:** Authorized SOC Laboratory

---

## 3. Hunt Objectives

The hunt was designed to answer the following questions:

1. Did `198.51.100.25` target accounts other than `root`?
2. Did other source IPs target `root`?
3. Did the source IP generate additional authentication activity?
4. Did successful authentication occur after repeated failures?
5. Is the observed activity isolated to the primary sequence?
6. Is there evidence of broader authentication targeting?
7. What additional telemetry would be required to continue the investigation?

---

## 4. Hunting Hypotheses

### Hypothesis H-001 — Source IP Broader Targeting

`198.51.100.25` may have attempted authentication against accounts other than `root`.

**Reason for hypothesis:**

An attacker conducting credential attacks may target multiple accounts rather than a single privileged account.

**Expected evidence if true:**

Additional failed or successful authentication events involving `198.51.100.25` and other usernames.

**Current assessment:**

No additional account targeting by the primary source IP was identified in the reviewed CASE-001 authentication telemetry.

---

### Hypothesis H-002 — Privileged Account Targeting From Multiple Sources

The `root` account may have been targeted by multiple source IP addresses.

**Reason for hypothesis:**

A privileged account can attract authentication attempts from multiple sources during password-guessing or scanning activity.

**Expected evidence if true:**

Multiple source IP addresses associated with failed SSH authentication against `root`.

**Current assessment:**

The available telemetry shows the primary sequence from `198.51.100.25`. Other authentication failures exist in the dataset, but they do not establish the same attack sequence.

---

### Hypothesis H-003 — Successful Access After Brute-Force Activity

The successful authentication represented by `EVT-001012` may have been preceded by the observed failure sequence.

**Expected evidence if true:**

A successful authentication event for the same source IP and username after multiple failed attempts.

**Current assessment:**

Confirmed in the available telemetry.

`EVT-001012` records successful authentication following eight failed attempts from `198.51.100.25` against `root`.

---

### Hypothesis H-004 — Post-Authentication Activity

The successful authentication may have been followed by suspicious endpoint or network activity.

**Expected evidence if true:**

Process execution, command activity, privilege changes, file modification, network connections, or other host events after `EVT-001012`.

**Current assessment:**

Cannot be determined from the currently available authentication telemetry.

## 8. Hunt Query 3 — Source and Account Correlation

### Objective

Determine whether the same source IP and username combination generated repeated authentication activity.

### Hunt Logic

Group authentication events by:

- `source_ip`
- `user`

Then count failed authentication events within the detection window.

### Expected Result

A repeated source/account combination may indicate focused credential attack behavior.

### Observed Result

The combination:

`198.51.100.25` + `root`

generated eight failed SSH authentication attempts within the configured detection window.

The sequence exceeded the DET-AUTH-001 threshold of five failures.

### Hunt Determination

**Confirmed threshold violation.**

---

## 9. Hunt Query 4 — Successful Authentication After Failures

### Objective

Identify successful authentications that occur after repeated failures from the same source and account.

### Hunt Logic

For each source IP and username combination:

1. Identify repeated failed authentication events.
2. Establish the failure sequence.
3. Search for a subsequent successful authentication.
4. Record the successful event ID.

### Expected Result

A successful authentication following repeated failures should receive increased investigation priority.

### Observed Result

`EVT-001012` records successful SSH authentication for `root` from `198.51.100.25` after eight failed authentication attempts.

### Hunt Determination

**Confirmed observed behavior.**

This is the primary hunting pivot for CASE-001.

## 12. Hunt Query 7 — Search for Repeated Failed Authentication

### Objective

Identify other source/account combinations that may resemble the primary brute-force pattern.

### Hunt Logic

Group failed authentication events by:

- source IP
- username

Count failures within the configured five-minute window.

### Expected Result

Other combinations reaching five or more failures should be reviewed as possible related or independent authentication attacks.

### Observed Result

The primary sequence involving:

`198.51.100.25` + `root`

reached eight failures.

Another source, `203.0.113.45`, generated four failures against `admin`, which is below the configured threshold.

The source `192.0.2.22` generated one failed authentication involving `bob` before a successful authentication.

### Hunt Determination

The primary sequence is the only reviewed sequence that clearly satisfies the five-failure threshold.

## 26. Final Hunting Statement

The threat-hunting activity successfully correlated the primary CASE-001 indicators and validated the suspicious authentication sequence.

The strongest hunting pivot is `EVT-001012`, representing successful SSH authentication following eight failed attempts from `198.51.100.25` against the privileged `root` account.

The available authentication telemetry does not provide sufficient evidence to determine whether the successful authentication resulted in compromise or malicious post-authentication activity.

Further hunting should focus on endpoint, identity, and network telemetry surrounding `EVT-001012`.

**Hunt determination: Primary suspicious authentication sequence confirmed; post-authentication impact remains undetermined.**
