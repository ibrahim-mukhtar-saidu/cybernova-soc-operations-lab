## Executive Summary

CASE-001 was generated after the authentication detection engine identified repeated failed SSH authentication attempts against the `root` account from source IP `198.51.100.25`.

The detection threshold was five failed SSH authentication attempts for the same source IP and user within a five-minute window. The supplied telemetry contains eight failed attempts within the detection window.

A successful SSH authentication for the same source IP and user was subsequently observed in event `EVT-001012`.

The available telemetry is consistent with an SSH brute-force authentication pattern followed by a successful authentication. The successful authentication is an observed event and does **not independently prove that the account was compromised**.

Additional identity, endpoint, network, and authorization evidence would be required to determine whether the successful authentication was legitimate or unauthorized.

Analyst Interpretation

The observed sequence is consistent with a brute-force authentication pattern.

The repeated failures followed by a successful authentication increase the investigative priority because the sequence could represent:

A legitimate user recovering from repeated authentication failures
An authorized security test
Misconfigured automation
A compromised credential being successfully used
An unauthorized authentication attempt

The available authentication telemetry alone cannot distinguish these possibilities with sufficient confidence.

Therefore:

Observed successful authentication ≠ confirmed account compromise.

The case remains open pending additional validation.

Initial Severity Assessment
Severity: HIGH

The alert is considered High because:

The targeted account is root.
