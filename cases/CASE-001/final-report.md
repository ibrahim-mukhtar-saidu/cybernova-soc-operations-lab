# CASE-001 — Final Incident Report

## 1. Executive Summary

CASE-001 was generated by `DET-AUTH-001`, a detection designed to identify repeated SSH authentication failures.

The detection identified eight failed SSH authentication attempts from source IP `198.51.100.25` against the privileged `root` account within the configured five-minute detection window.

The repeated failures exceeded the configured threshold of five attempts.

A subsequent successful SSH authentication was recorded as `EVT-001012` for the same source IP and account.

The sequence increased the investigation priority because successful authentication followed repeated failures against a privileged account.

The available evidence confirms the authentication sequence but does not independently establish account compromise, malicious execution, persistence, lateral movement, or data impact.

The case therefore remains classified as suspicious authentication activity requiring investigation, with compromise **not confirmed**.

## 17. Detection Engineering Assessment

The case demonstrates that `DET-AUTH-001` successfully identified the primary authentication pattern.

The investigation also identifies opportunities to improve detection coverage.

Recommended improvements:

1. Detect repeated SSH failures followed by successful authentication.
2. Increase severity for privileged-account targeting.
3. Correlate authentication events with endpoint telemetry.
4. Correlate authentication events with network telemetry.
5. Detect source IP targeting multiple accounts.
6. Detect source IP targeting multiple hosts.
7. Add regression tests for successful-after-failure scenarios.
8. Measure false-positive behavior.
9. Tune thresholds using validated laboratory scenarios.
