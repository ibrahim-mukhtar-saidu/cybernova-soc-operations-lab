# CASE-005 — Threat Hunting

## Hunting Objective

Perform retrospective and pivot-based hunting around the suspicious network activity identified by DET-NET-001.

The objective is to determine whether the observed process, destination, host, or behavioral pattern appears elsewhere in the available laboratory telemetry.

All hunting is limited to synthetic laboratory data.

## Hunt 1 — Process Name

**Query:** Search for `svchost_update.exe`.

**Expected pivot:**

- Process execution events.
- Network connections generated by the process.
- Process/network correlation events.

**Observed laboratory result:**

`svchost_update.exe` appears in EVT-005006 and the suspicious network sequence EVT-005007–EVT-005014.

**Assessment:** Positive pivot.

## Hunt 2 — Process Path

**Query:** Search for:

`C:\Users\Public\svchost_update.exe`

**Expected pivot:**

Identify all telemetry associated with execution from the same path.

**Observed laboratory result:**

The path is observed in EVT-005006 and associated with the suspicious process.

**Assessment:** Positive pivot.

## Hunt 3 — Destination IP

**Query:** Search for:

`198.51.100.77`

**Expected pivot:**

Identify all hosts and processes communicating with the destination.

**Observed laboratory result:**

The destination appears in EVT-005007–EVT-005014.

All observed connections originate from `lab-ws-01` and are associated with `svchost_update.exe`.

**Assessment:** Positive pivot limited to the available laboratory telemetry.

## Hunt 4 — Destination Port

**Query:** Search for outbound connections to TCP port `8443`.

**Expected pivot:**

Identify processes using the destination port and determine whether the behavior is isolated or repeated.

**Observed laboratory result:**

The suspicious sequence uses TCP port 8443.

**Assessment:** Positive behavioral pivot.

## Hunt 5 — Destination Domain

**Query:** Search for:

`cdn-update.example`

**Expected pivot:**

Identify network events associated with the destination domain.

**Observed laboratory result:**

The domain appears in the suspicious network telemetry.

**Assessment:** Positive pivot within the laboratory scenario.

## Hunt 6 — Host Pivot

**Query:** Search for all network activity originating from:

`lab-ws-01`

**Expected pivot:**

Compare suspicious activity against normal host traffic.

**Observed laboratory result:**

The host contains:

- benign Chrome HTTPS traffic;
- suspicious `svchost_update.exe` network activity;
- expected Windows update traffic.

**Assessment:** Useful host-level comparison confirms that the host generated both benign and suspicious laboratory activity.

## Hunt 7 — Source IP Pivot

**Query:** Search for:

`192.0.2.50`

**Expected pivot:**

Identify all network activity originating from the source address.

**Observed laboratory result:**

The source address is associated with the suspicious host/process activity.

**Assessment:** Positive pivot within the laboratory dataset.

## Hunt 8 — Process/Network Correlation

**Query:** Search for process/network correlation involving:

- Process: `svchost_update.exe`
- Destination: `198.51.100.77`
- Destination port: `8443`

**Expected pivot:**

Identify correlation events that associate endpoint process characteristics with network behavior.

**Observed laboratory result:**

EVT-005013 records:

- connection count: 6;
- interval: 60 seconds;
- unsigned binary: true;
- user-writable path: true;
- classification: high_confidence_suspicious.

**Assessment:** Strong supporting correlation evidence.

## Hunt 9 — Beaconing Pattern

**Query:** Search for repeated outbound connections with:

- the same source host;
- the same process;
- the same destination;
- regular time intervals.

**Expected pivot:**

Identify periodic network behavior that may indicate automated communication.

**Observed laboratory result:**

Seven connections from `svchost_update.exe` to `198.51.100.77:8443` occur at consistent 60-second intervals.

**Assessment:** Strong behavioral match to the DET-NET-001 detection hypothesis.

## Hunt 10 — Process Name Across Hosts

**Query:** Search all available telemetry for:

`svchost_update.exe`

**Objective:**

Determine whether the process is isolated to `lab-ws-01` or appears on additional hosts.

**Observed laboratory result:**

The current CASE-005 telemetry contains the process on `lab-ws-01`.

No additional-host evidence is available in this case dataset.

**Assessment:** No cross-host propagation can be established from the available telemetry.

## Hunt 11 — Destination Across Hosts

**Query:** Search all available telemetry for:

`198.51.100.77`

**Objective:**

Determine whether multiple hosts communicate with the same destination.

**Observed laboratory result:**

The CASE-005 dataset shows communication from `lab-ws-01`.

No additional-host communication is present in the available case telemetry.

**Assessment:** Cross-host infrastructure reuse cannot be established from this dataset.

## Hunt 12 — Benign Comparison

**Query:** Compare outbound network activity from `lab-ws-01` against known benign events.

**Observed baseline:**

- Chrome → `93.184.216.34:443`
- Windows update → `203.0.113.80:443`

These activities differ from the suspicious sequence in process identity, destination, process path, signing status, and behavioral regularity.

**Assessment:** Useful negative evidence against treating all outbound connections as suspicious.

## Hunting Summary

The available telemetry supports multiple independent pivots:

- process name;
- process path;
- source host;
- source IP;
- destination IP;
- destination port;
- destination domain;
- process/network correlation;
- periodic connection behavior.

All successful pivots converge on the same suspicious process and network sequence.

No evidence in the available CASE-005 dataset demonstrates:

- additional compromised hosts;
- lateral movement;
- data exfiltration;
- confirmed remote command execution;
- persistence;
- real-world threat infrastructure;
- threat-actor attribution.

## Detection Feedback

The hunting results support the current DET-NET-001 detection logic because multiple independent pivots converge on the same event sequence.

Future detection improvements should consider additional context such as:

- process ancestry;
- executable hash;
- certificate information;
- DNS relationships;
- proxy telemetry;
- historical destination prevalence;
- host prevalence;
- additional endpoint telemetry.

These improvements should be validated against both suspicious and benign laboratory telemetry before deployment.

## Hunting Limitations

This hunting exercise is constrained by the available CASE-005 synthetic telemetry.

Absence of an indicator from this dataset does not demonstrate absence from a real environment.

The results should therefore be interpreted as laboratory hunting evidence rather than enterprise-wide threat-hunting conclusions.
